# CHANGELOG

Все изменения SPEC.md, TEST_CASES.md и тестов **после заморозки** фиксируются здесь. Каждое изменение теста сопровождается regression-тестом (новый TC-ID).

Формат записи:

```
## [версия] — ГГГГ-ММ-ДД
- Что изменено: <раздел SPEC / TC-ID / тест>
- Почему: <ссылка на замечание ревьюера, BUGREPORT.md или FIXES.md>
- Классификация (на этапе приёмки): код / тест / ТЗ
- Regression-тест: <TC-ID, имя метода>
```
